# Portafolio - Catálogo interactivo

Prototipo interactivo gamificado creado para el curso. Para desplegar en GitHub Pages, ve a Settings → Pages y selecciona la rama `feature/catalogo-interactivo` y la carpeta `/ (root)` o mergea esta rama a la rama por defecto.

Instrucciones rápidas:
- Reemplaza los placeholders de imágenes en `assets/images/` con los logos y recursos reales.
- Reemplaza `assets/audio/background-loop.mp3` con la pista de audio deseada (formato mp3).
- Edita `assets/data/catalogo.json` para ampliar fichas y preguntas.

Notas sobre licencias y recursos:
- Las imágenes institucionales deben usarse conforme a las políticas de la Universidad César Vallejo.
- Audio placeholder no está incluido; añade tu pista y verifica derechos.
